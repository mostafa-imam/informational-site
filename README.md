# Informational Site

A simple Node.js project built as part of The Odin Project to practice the basics of creating a web server.

## How to run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/informational-site.git
   ```
2. Navigate into the project folder:
   ```bash
   cd informational-site
   ```
3. Start the server:
   ```bash
   node index.js
   ```
4. Open your browser and go to `http://localhost:8080`
